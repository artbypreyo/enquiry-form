# Art By Preyo enquiry site

A separate React/Vite enquiry website with the same logo, colours, and background as the Art By Preyo social links page.

## Run locally

```bash
npm install
npm run dev
```

## How enquiries arrive

- **Send enquiry by email** posts to FormSubmit, which forwards submissions to `kundupreyasi1997@gmail.com`. FormSubmit's free service requires the owner to click the activation link sent after the first live submission. Until that activation is complete, email delivery is not active. Do a real test from the published site before putting the URL on a printed card. Submissions pass through FormSubmit's service.
- **Continue on WhatsApp** opens a prefilled message to `+91 8918665336`. The visitor must tap Send in WhatsApp.
- The thank you screen is shown after FormSubmit redirects back to this page with `?sent=1`.

This project is local only for now. When it is published at a stable address, add that exact address to the business card and test it on a phone before printing.
